## 2. What "always" access requires (your actual ask)

You asked for the app to "always" reach the hard drive, not just these specific dev folders. Two separate things determine that:

1. **Which folders are connected.** Right now: the 11 `beamthinktank.space` site folders under `~/Desktop/local dev/`. Nothing outside those (e.g. `Desktop`, `Documents`, `Downloads` at the top level) is reachable without you approving a new folder request — each request pops a permission prompt on your Mac, so I never do this silently. If you want a Claude session to reach anything on the laptop by default, the cleanest fix is connecting `~/Desktop/local dev/` itself (the parent) once, rather than 11 individual subfolders — one approval covers all current and future BEAM site repos.
2. **Whether the link is live.** The link between a Claude session and your laptop depends on the Claude desktop app being open and online on that machine. When it's closed or asleep, no session — mine or a future one — can reach the drive at all, regardless of what's approved. That's a per-session fact, not something a plan can fix in advance.

**Recommendation:** when you have a moment, (a) fix the GitHub token in the local `github` MCP server's config, (b) update/restart the local `filesystem` MCP server (or remove it — the plain device-bridge tools above already cover its job more reliably), and (c) consider connecting the parent `local dev` folder instead of each site individually. None of these are urgent tonight.
